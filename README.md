# Orange Bar — сайт-візитка

Статичний сайт: без сервера, бази даних і збірки.

## Як запустити
- Відкрийте `index.html` у браузері, або
- у цій папці виконайте `python3 -m http.server 8000` і відкрийте http://localhost:8000

## Структура
- `index.html` — розмітка
- `css/styles.css` — стилі (кольори й шрифти на початку файлу, у `:root`)
- `js/app.js` — логіка (мобільне меню, нижня панель, виведення меню)
- `menu.js` — **усі дані: меню, ціни, години, контакти, фото**
- `img/` — фото
- `_headers` — заголовки безпеки для хостингу

## Що де змінювати
- **Меню і ціни, години, посилання** — лише `menu.js`.
- **Телефон** — у `menu.js` поставте `phoneConfirmed: true`, коли номер підтверджено (зараз прихований).
- **Фото** — покладіть у `img/` файли з іменами з `menu.js`. Дозволені формати: jpg, png, webp, avif; ім'я — латиниця, цифри, `-`, `_`. Поки файлу немає, показується заглушка.

## Безпека
- Content-Security-Policy: скрипти лише з власного сайту, без inline-скриптів і `eval`; дозволені тільки Google Fonts.
- Дані з `menu.js` виводяться лише як текст (`textContent`), тож HTML/скрипт у назві страви не виконається.
- Посилання приймаються лише `https://`, телефон — лише цифри та `+`, фото — лише з папки `img/`.
- Усі зовнішні посилання з `rel="noopener noreferrer"`.
- Немає форм, cookies, аналітики і збору даних.
- На хостингу додайте заголовки з `_headers` (Netlify і Cloudflare Pages підхоплюють файл самі).
  Для nginx — ті самі рядки через `add_header`, напр. `add_header X-Frame-Options DENY always;`.
  `frame-ancestors` і HSTS працюють лише як заголовки сервера, не через `<meta>`.
- Сайт викладайте тільки по HTTPS.
- Шрифти завантажуються з Google Fonts. Якщо хочете без сторонніх запитів — покладіть woff2-файли
  Unbounded і Manrope в `fonts/`, підключіть через `@font-face` у `styles.css`, приберіть посилання на
  Google Fonts з `index.html` і з CSP.
